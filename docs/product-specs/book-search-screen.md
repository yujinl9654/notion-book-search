# Book Search Screen

## 개요

첫 기능은 사용자가 Notion 페이지에 임베드한 작은 위젯에서 키워드로 책을 검색하고, 반환된 결과를 입력창 아래 드롭다운 목록으로 확인할 수 있는 화면입니다.

이 화면은 저장소의 첫 구현 대상입니다. 빠르게 만들 수 있을 만큼 작아야 하고, 동시에 하네스 기반 개발이 가능할 만큼 동작이 분명해야 합니다.

## 사용자 목표

사용자는 Notion 문서를 벗어나지 않고 검색어를 입력한 뒤, 일치하는 도서가 있는지 빠르게 확인하고 싶어 합니다.

## 주요 사용자 흐름

1. 사용자가 도서 검색 화면에 진입합니다.
2. 검색 입력창과 검색 실행 수단을 확인합니다.
3. 제목, 저자명, ISBN 형태의 텍스트 같은 키워드를 입력합니다.
4. 검색을 실행합니다.
5. 결과를 가져오는 동안 입력창 아래 드롭다운 영역은 로딩 상태를 보여줍니다.
6. 화면은 아래 셋 중 하나의 최종 상태를 보여줍니다.
   - 결과 드롭다운 목록
   - 빈 결과 상태
   - 오류 상태

## 핵심 UI 요소

- 작은 위젯 안에서 화면 목적을 보여주는 제목
- 검색 입력창
- 검색 버튼 또는 이에 준하는 명시적 실행 수단
- 요청 진행 중임을 알리는 로딩 피드백
- 입력창 아래 드롭다운 결과 목록 영역
- 검색 결과가 없을 때의 빈 상태 메시지
- 요청 실패 시의 오류 메시지

## 결과 카드에 표시할 데이터

첫 단계에서는 사용자가 책을 식별하기 쉬운 필드를 우선 노출합니다.

- 제목
- 저자
- 출판사
- 출간 연도 또는 날짜
- 썸네일 이미지

데이터 소스에 따라 일부 필드가 비어 있어도 목록 전체가 깨지지 않아야 합니다.

## 상태 모델

### 초기 상태

- 입력창이 보입니다.
- 이전 오류가 남아 있지 않습니다.
- 사용자가 책을 검색할 수 있다는 맥락이 보입니다.

### 로딩 상태

- 유효한 검색이 시작되면 눈에 보이는 로딩 표시가 나타납니다.
- 사용자는 요청이 진행 중이라는 사실을 알 수 있어야 합니다.

### 성공 상태

- 일치하는 책이 입력창 아래 드롭다운 목록으로 나타납니다.
- 각 결과는 빠르게 비교할 수 있을 정도로 구분되어야 합니다.

### 빈 결과 상태

- 일치하는 책이 없다는 메시지가 명확하게 보입니다.
- 사용자는 같은 화면에서 다른 검색을 다시 시도할 수 있어야 합니다.

### 오류 상태

- 검색 실패 사실이 명확하게 보입니다.
- 사용자는 같은 검색어나 다른 검색어로 다시 시도할 수 있어야 합니다.

## 수용 조건

- 사용자는 눈에 보이는 입력창과 실행 수단으로 검색을 시작할 수 있어야 합니다.
- 비어 있지 않은 검색어는 실제 검색을 시작하고 로딩 상태를 보여줘야 합니다.
- 성공 응답은 입력창 아래 드롭다운 결과 목록을 렌더링해야 합니다.
- 성공 응답이지만 결과가 0건이면 빈 영역 대신 빈 결과 상태를 보여줘야 합니다.
- 실패 응답이면 로딩 상태에 멈추지 않고 오류 상태를 보여줘야 합니다.
- 결과 항목의 선택적 필드가 비어 있어도 목록 렌더링이 깨지면 안 됩니다.
- 성공, 빈 결과, 오류 이후에도 사용자는 다시 검색할 수 있어야 합니다.

## 현재 범위 밖

- 고급 필터
- 저장된 검색어
- 최근 검색 기록
- 페이지네이션
- Notion 저장 액션
- 기본 폼 제출을 넘어서는 추가 키보드 단축키

## 가정

- 도서 검색 화면은 Notion 임베드 위젯으로 사용됩니다.
- 첫 단계에서는 Notion 저장 액션보다 검색 결과 확인 경험에 집중합니다.
- 첫 마일스톤에서는 시각적 장식보다 임베드 환경에서의 단순함과 검증 가능성을 더 우선합니다.
- 첫 구현 스택은 React, TypeScript, Tailwind CSS를 사용합니다.
- 첫 구현은 실제 API 대신 목 데이터로 상태 전환과 결과 렌더링을 먼저 검증합니다.

## 현재 구현 상태

- 초기 진입 시 작은 검색 위젯과 입력창이 보입니다.
- 검색은 목 데이터에서 제목, 저자, 출판사, ISBN 기준으로 동작합니다.
- 검색 결과는 입력창 아래 드롭다운 영역에서 성공, 빈 결과, 오류 상태로 나뉘어 렌더링됩니다.
- `error`가 포함된 검색어는 개발용 오류 상태를 재현합니다.
- 일부 목 데이터는 썸네일, 출판사, 출간일이 비어 있어 선택적 필드 누락 케이스를 함께 확인할 수 있습니다.
- 현재 구현은 공용 `Book` 타입과 상태 타입을 기준으로 화면과 검색 로직을 맞추고 있습니다.
